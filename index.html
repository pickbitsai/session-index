Local-only by design

No login, no telemetry, no cloud database.

The server listens only on 127.0.0.1. Scanning is limited to sessions whose recorded working folder is inside your project root.

  • Reads session IDs, working folders, timestamps, model and usage metadata, titles, and short prompt excerpts from local profile stores.
  • Codex summaries use the first useful user prompt. Claude summaries prefer its recorded last prompt, then fall back to the first useful user prompt. Names and summaries can be overridden.
  • Makes no outbound network requests and loads no remote scripts, fonts, analytics, or advertisements.
  • Saves your shortlist in this browser only. JSON exports may contain prompt excerpts, so treat backups as private.
